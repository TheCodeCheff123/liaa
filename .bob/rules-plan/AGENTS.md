# Project Architecture Rules

- Project is pre-scaffold; no architecture exists yet.
- Design assets suggest e-commerce frontend with 3D elements — plan for a framework that supports both (e.g., Next.js + Three.js/React Three Fiber).
- Cart popup and contact section designs imply at minimum: product listing, cart state management, and a contact form.
- Two logo variants (normal + white) suggest light/dark theme support is expected.
